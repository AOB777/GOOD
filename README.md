## ✨ Descripción

**G.O.O.D** es una plataforma de delivery de lujo que conecta tres roles principales:

- 🛍️ **Compradores** - Exploran y adquieren productos exclusivos
- 🏪 **Vendedores** - Publican y gestionan sus productos
- 🚚 **Repartidores** - Realizan entregas y gestionan pedidos
- 👑 **Administrador** - Gestiona usuarios y supervisa la plataforma

## 🛠️ Tecnologías

- **Backend:** PHP (nativo) + MySQL
- **Frontend:** HTML5, CSS3, JavaScript
- **Framework CSS:** Bootstrap 5.3
- **Iconos:** Font Awesome 6

## 📋 Requisitos

- XAMPP / WAMP / LAMP
- PHP 7.4 o superior
- MySQL 5.7 o superior
